# 統計からみた埼玉県市町村のすがた

Netlifyで公開する静的ダッシュボードです。

## ファイル
- `index.html`: ダッシュボード本体
- `ogp.jpg`: OGP画像（1200×630、右上の埼玉県白地図を削除済み）
- `netlify.toml`: 公開ディレクトリとヘッダー設定
- `_redirects`: 直接アクセス時のフォールバック
- `robots.txt`: 検索エンジン向け設定

## 公開
この一式をGitHubリポジトリのルートへ配置し、Netlifyで当該リポジトリを連携してください。Build commandは空欄、Publish directoryは `.` です。

## OGP確認
デプロイ後、ページソースで `og:image` が `/ogp.jpg` を参照していること、公開URLの `/ogp.jpg` がブラウザーで開けることを確認してください。SNS側に旧画像のキャッシュが残る場合は、各SNSのシェアデバッガーで再取得してください。
