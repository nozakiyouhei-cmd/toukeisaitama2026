# 統計からみた埼玉県市町村のすがたダッシュボード

埼玉県内市町村の統計を比較・可視化し、自治体の特徴や課題を把握するための静的HTMLダッシュボードです。

## ファイル構成

- `index.html`: ダッシュボード本体。データ、CSS、JavaScriptを内包しています。
- `netlify.toml`: Netlifyの公開ディレクトリとセキュリティヘッダーの設定です。
- `.gitignore`: OS・エディター由来の不要ファイルを除外します。

## GitHubからNetlifyへ公開

1. このフォルダー内のファイルをGitHubリポジトリのルートに配置してpushします。
2. Netlifyで **Add new project** → **Import an existing project** を選択します。
3. GitHubを選び、対象リポジトリを指定します。
4. ビルドコマンドは空欄、公開ディレクトリは `.` とします。`netlify.toml` があるため通常は自動認識されます。
5. **Deploy** を実行します。

## 更新方法

`index.html`を更新してGitHubへpushすると、Netlify側で再デプロイされます。

## 注意事項

- 現在は単一HTML方式のため、そのまま静的配信できます。
- 公開前に、掲載データの出典、利用条件、個人情報・機密情報の有無を確認してください。
